# Security Incident Playbook
Document ID: DOC-102
Classification: Manager and Admin
Owner: IT Security
Last updated: 2026-09-12

## Suspected account compromise
1. Notify the IT security contact immediately.
2. Disable or suspend the affected account according to company procedure.
3. Preserve relevant logs for investigation.
4. Record the incident reference and actions taken.

## Suspicious AI response
Capture the question, response, timestamp, and request ID. Do not copy restricted document contents into public channels.
